Install on Android

Download the signed Android app from this website.

  1. 1Tap Download Android app above to download the signed APK from this website.
  2. 2Open the downloaded APK. If Android asks, allow this browser to install apps.
  3. 3Review Android’s installer prompt and tap Install.

Android keeps the final say. The browser cannot silently install an APK; Android shows its own confirmation before installation.

Use on iPhone or iPad

Add the web app from Safari.

  1. 1Open this page in Safari, then tap the Share button.
  2. 2Choose Add to Home Screen.
  3. 3Tap Add. The hymnal opens from its new Home Screen icon.

No iPhone APK needed. The web app is the installable option on iPhone; an Android APK cannot be installed on iOS.

Updates stay in sync. This page links to the latest signed Android APK. The installed app checks for signed APK updates, downloads the APK, and opens Android's installer. Android asks you to confirm before replacing the app.
