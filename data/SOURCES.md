# CAC hymn text sources and rights notes

## Included collections

- CAC Gospel Hymn Book (CAC GHB): 152 English records in the current photographed index, drawn from [HymnFlow’s CAC GHB data](https://github.com/ebena107/HymnFlow/blob/master/hymn-bundle/cac_ghb.json).
- CAC Yoruba Hymn Book (CAC YHB / Iwe Orin CAC): 152 active Yorùbá records selected from [HymnFlow’s CAC YHB data](https://github.com/ebena107/HymnFlow/blob/master/hymn-bundle/cac_yhb.json); the full 997-record source archive remains in `data/cac-yhb.js`.

The member app and admin use the current 152-record English index and Yorùbá entries whose printed numbers appear in that English index. This selects 152 Yorùbá records across 151 distinct printed numbers because the source has two separate entries numbered 10; English number 392 has no Yorùbá entry. Yorùbá titles and lyrics remain as published in the source. Equal printed numbers are only the selection rule, not a verified translation mapping. The active Yorùbá data is generated by `npm run build:current-yhb`; the full source archive is kept separately. Meter-only English headings use the first lyric line as the displayed title when available. Records flagged as part of a Various section use a V suffix to distinguish intentional repeated printed numbers. App-internal IDs are unique and are not printed hymn numbers.
