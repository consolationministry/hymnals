# Hymn text sources and rights notes

## Included collections

- CAC Gospel Hymn Book (CAC GHB): 152 English records in the current photographed index, drawn from [HymnFlow’s CAC GHB data](https://github.com/ebena107/HymnFlow/blob/master/hymn-bundle/cac_ghb.json).
- CAC Yoruba Hymn Book (CAC YHB / Iwe Orin CAC): 152 active Yorùbá records selected from [HymnFlow’s CAC YHB data](https://github.com/ebena107/HymnFlow/blob/master/hymn-bundle/cac_yhb.json); the full 997-record source archive remains in `data/cac-yhb.js`.
- User-provided English DOCX: 128 unique hymn entries were reviewed; 99 matching same-number hymns were consolidated with the current English records, and 29 distinct entries remain as additions.

The app and admin present the current English catalog, current Yorùbá entries, and the DOCX additions under one visible “Consolation Hymn” collection. The active bundle contains 152 English records, 152 Yorùbá records, and 29 distinct DOCX additions. Matching same-number entries are represented once in the active list; six alternate document headings use the document title on the existing English record. Twenty-four additions use numbers absent from the current English index. Five different songs with an already-used number remain as variants and display a V suffix. The original source labels remain in metadata for provenance. This selects 152 Yorùbá records across 151 distinct printed numbers because the source has two separate entries numbered 10; English number 392 has no Yorùbá entry. Equal printed numbers are only the selection rule, not a verified translation mapping. The active Yorùbá data is generated by `npm run build:current-yhb`; the full source archive is kept separately. Meter-only English headings use the first lyric line as the displayed title when available. App-internal IDs are unique and are not printed hymn numbers.
